# 트러블슈팅 로그

이 파일은 **반복되는 문제와 해결**을 누적합니다. Docker·호스트 권한 이슈는 풀스택 보일러플레이트 저장소에서 주로 발생하며, 이 저장소는 정적 배포 위주입니다.

## GitHub Pages

### 증상: CSS/JS가 로드되지 않음

- **원인**: `index.html`의 `href`/`src`가 상대 경로가 아니거나, Pages가 서브패스에 배포되는데 루트 기준 링크를 씀.
- **조치**: User/Organization Pages(`username.github.io`)는 보통 저장소 루트가 사이트 루트입니다. Project Pages라면 `base` 태그 또는 경로 접두사를 맞춥니다.

### 증상: 이미지(노연호.jpg) 404

- **원인**: 파일 미커밋, 대소문자 불일치(Linux 서버는 구분), 파일명 인코딩.
- **조치**: 저장소에 이미지가 포함되어 있는지 확인하고, HTML의 `src`와 실제 파일명을 일치시킵니다.

### 증상: 변경이 반영되지 않음

- **원인**: 브라우저 캐시, CDN 지연, 잘못된 브랜치 푸시.
- **조치**: 하드 리로드, 시크릿 창, GitHub 저장소 **Actions / Pages** 빌드 완료 여부 확인.

## 로컬 미리보기

### 증상: `file://`로 열 때 일부 동작이 다름

- **조치**: `python3 -m http.server` 등으로 HTTP로 서빙합니다.

## 다국어(i18n)

### 증상: 영어 전환 시 일부만 번역됨

- **원인**: 해당 요소에 `data-i18n` 누락 또는 `translations`에 키 없음.
- **조치**: HTML 키와 `ko`/`en` 객체 키를 동기화합니다.
