# 노연호 — 개인 소개 페이지
정적 HTML/CSS/JavaScript로 만든 **개인 소개 웹사이트** 저장소입니다.
**라이브 사이트:** [https://wesroh-ops.github.io](https://wesroh-ops.github.io)
## 구성
| 파일 | 설명 |
|------|------|
| `index.html` | 메인 페이지 |
| `style.css` | 스타일 |
| `script.js` | 인터랙션·동작 |
| `노연호.jpg` | 프로필 이미지 |
| `자기소개.txt` | 소개 문구 초안·참고용 텍스트 |
## 기술 스택
- HTML5  
- CSS3  
- Vanilla JavaScript (별도 프레임워크 없음)
## 로컬에서 보기
1. 저장소를 클론한 뒤 `index.html`을 브라우저에서 직접 열거나  
2. 간단한 정적 서버로 확인합니다.
